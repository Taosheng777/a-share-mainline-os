# v0.4.0-beta.1 更新说明

本次更新将较新的日常研究方法整理为公开可配置能力。原有复盘、载体筛选、常规分析和专家模式入口保留；新增研究运行层默认关闭，升级不会启用它或修改使用者的 vault。

## 新增与修复

- 连续研究账本记录主题、判断、前序条件、证据可得时间、改判原因和真实执行来源。追加幂等、哈希链和本机文件锁帮助发现记录错误；不宣称防篡改或跨设备分布式锁。
- 同载体影子比较区分合成测试、历史诊断和前瞻模拟。前瞻模拟核对完整锁定记录，以实际系统录入时间决定最早可研究执行的开盘；修复跨午夜与盘前决定被误拒绝的问题。
- 配置检查覆盖 vault 内路径、方法版本、模型标识、账本与可选运行文件指纹；空指纹不能被报告为校验通过。工程通过不建立盈利资格。
- 随包补齐市场宽度与完整行业排名工具。分页中断、重复、总数变化、数据日不符和无完整缓存凭证时拒绝把残页当完整市场；封板价来自当日行情源，不按 ST 名称猜测。
- 数据降级仅尝试支持且获准的通道。问财限正面清单，以单轮消耗预算代替旧的15:00重复确认；单项失败保留其他独立工作。
- 外部 a-stock-data 固定至 v3.9.0 的已核验提交与文件指纹，技术面改用腾讯K线与可选通达信盘后包。上游源码仍由使用者单独安装，不随仓库分发。
- 公开脚本默认保留对外声明；本人本地输出可显式选择 personal，来源、日期及证据边界始终保留。

## 升级

按 [升级与回滚](升级与回滚.md) 更新三个产品技能。外部数据技能单独更新；已有定制版先审阅并保留备份，不要直接覆盖。需要连续研究时再按 [研究运行层](研究运行层.md) 配置，空模板没有任何历史判断或收益资格。

本仓库不附带作者的持仓、纪律阈值、主线案例、账本、付费凭据或项目专用 decision_ops 实现。后者只提供可选的配置接入约定，不能据此声称候选回填或行动到期处理已经可用。

## 验证范围

离线行为回归、双平台确定性导出、合成案例、全新 HOME 安装/升级/回滚与脱敏审计覆盖工程可用性。外部公开接口可能失效或限流，在线检查只代表本次探测。没有验证真实账户、收益优势或全部第三方端点。
