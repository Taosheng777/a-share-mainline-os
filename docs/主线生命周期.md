# 主线生命周期

| 阶段 | 进入条件 | 退出或升级 |
|---|---|---|
| 提名 | AI 给出叙事、证据、反方和死亡条件雏形 | 用户说“跟”才立项 |
| 启动 | 催化、资金和价格开始共振 | 证据增强进入发酵；冲突进入分歧 |
| 发酵 | 资金持续、宽度扩散、载体确认 | 分化进入分歧；死亡条件成立转退潮 |
| 分歧 | 资金、价格或宽度信号冲突 | 修复后回发酵；死亡条件成立转退潮 |
| 退潮 | 预注册的清仓级死亡条件成立 | 提示纪律①并建议复核，不自动交易 |
| 归档 | 退潮证据链与复核结论建立 | 只读保留；重新成立时走新立项，不原地复活 |

## 防锚定接力

机械候选池和正式提名是两个不同角色：前段只输出资金与宽度候选，不作取舍；后段必须先独立扫描，再看候选池并取并集，最后用催化剂、反方和死亡条件筛成 0–3 条正式提名。候选池不得写成“提名”。

## 死亡条件

- 立项前写；不得事后按行情改写。
- 必须给出标的或指数代码、基线点位和基线数据日。
- 依赖连续序列时必须能从外部数据回溯；不能回溯就标“不可判定”。
- 触发只产生纪律提示与 AI 建议，不产生委托。
