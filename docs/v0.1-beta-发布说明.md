# v0.1-beta 发布说明

`a-share-mainline-os` 的首个 beta 版把作者日常使用的 A 股主线工作流整理成可移植、可审计、可在 Claude Code 与 Codex 使用的产品版。

## 这一版能做什么

- `stock-daily`：复盘最新有效交易日，判定市场环境与主线状态，并对照用户自己的纪律事实。
- `stock-screener`：为已立项主线发现 ETF 与龙头股，做相关度校验和四维排序。
- `stock-buddy`：论证或体检主线、持仓和退潮信号；用户显式开启时运行五维专家模式。

核心不是预测涨跌，而是把主线生命周期、证据链、反方理由、改判条件和纪律边界放进同一个可复核流程。系统不代下单；输入或证据不足时保持缺口，不制造个性化目标区间或仓位。

## 安装

Codex：

```bash
codex plugin marketplace add Taosheng777/a-share-mainline-os
codex plugin add a-share-mainline-os@a-share-mainline-os
```

Claude Code：

```text
/plugin marketplace add Taosheng777/a-share-mainline-os
/plugin install a-share-mainline-os@a-share-mainline-os
```

随后复制 `vault-template/` 与 `config/config.example.json`，填写自己的 vault 绝对路径和纪律字段。完整步骤见仓库的 `docs/五分钟上手.md`。

## 已验证

- Python 3.11 与 3.12 的 GitHub Actions 离线门均通过。
- 两个平台共执行 310 项 Skill 测试；加产品合同与 vault 合同共 326 项测试。
- 全新临时 HOME 中完成 Codex marketplace 安装、空 vault 校验、复盘离线前置流程和离线载体筛选。
- 手动 `Live smoke` 成功验证固定的 `a-stock-data v3.6.1` revision、`SKILL.md` 指纹和腾讯免费行情主干。
- 发布审计结果：私人路径 0、疑似凭据 0、账户附件 0；两个插件分发树均含 LICENSE 与 NOTICE。

## Beta 边界

- 真实交易日复盘仍依赖用户自行安装的数据 Skill 或可选数据服务；接口可能变化、限流或失效。
- `hithink-finance`、问财、iFinD helper、新闻与研报搜索均为外部可选组件，不包含在发行包中。
- beta 期间可能调整配置、模板和输出结构；升级前建议备份自己的 vault，并阅读 `CHANGELOG.md`。

本工具仅用于研究与决策支持；提供方非持牌证券投资咨询机构，本工具及其输出不构成投资建议，不代下单，使用者风险自担。数据来源与数据日以每次运行输出为准。
