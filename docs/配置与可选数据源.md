# 配置与可选数据源

## 最小配置

将 `config/config.example.json` 复制到 `~/.config/a-share-mainline/config.json`，把 `__VAULT_ROOT__` 换成脱敏模板或自己的 vault 绝对路径。也可用 `ASM_CONFIG` 指向其他 JSON。

必填项只有：

```json
{
  "schema_version": 1,
  "vault_root": "/absolute/path/to/vault",
  "git_identity": {
    "default": "[ai]",
    "claude": "[ai:claude]",
    "codex": "[ai:codex]"
  }
}
```

没有 `vault_root` 时 fail closed，不猜路径。

`schema_version` 用于识别配置合同；升级器不会改写用户现有 JSON。`doctor` 会只读验证配置与 vault：

```bash
python3 scripts/doctor.py --platform codex
```

## a-stock-data

`a-stock-data` 是外部 Apache-2.0 Skill。本仓库固定兼容并校验 `v3.6.1`：

```bash
python3 adapters/shared/install_a_stock_data.py \
  --target "$HOME/.codex/skills/a-stock-data"
```

Claude 用户把目标改为 `$HOME/.claude/skills/a-stock-data`。脚本核对 tag commit 和 `SKILL.md` SHA-256，并保留上游许可证；本仓库不复制上游源码。

## 板块逐日缓存（自带，建议第一天就开始养）

`stock-daily/scripts/board_fund_flow_cache.py` 是**本仓库自有代码**，不属于上游 `a-stock-data`。它把全板块逐日主力净额、四档资金和板块收盘点位存进本地 SQLite，是下面四件事的前提：

- MA20 等**价格键**计算；
- 「连续 N 日」类死亡条件在断更后的**回溯判定**；
- 立项时的**误报回测**（过去 60 个交易日触发几次）；
- 退潮判定 **T+N 台账**回填与复活哨。

库位置由 `A_STOCK_DATA_HOME` 指定，未设置时落在该脚本内置的用户级数据目录。每个交易日收盘后续接一次：

```bash
python3 <skills_root>/stock-daily/scripts/board_fund_flow_cache.py \
  snapshot --trade-date YYYY-MM-DD
```

命令**幂等且自带交易日守卫**，复盘流程本身也会跑这一步。想让它更早跑完，可以自己在系统里排定时任务——**Skill 永远不会替你创建定时任务或后台监控**。

`doctor` 会报告当前覆盖了多少个交易日：

```bash
python3 scripts/doctor.py --platform codex
```

**缓存是逐日累积的，新装时几乎没有历史，这是正常的。**覆盖不足、末日与判定日不匹配或跨源冲突时，所有依赖它的判定一律写「本项未验证」，**不会默认判「未触发」**，也不阻断其余复盘区。历史缺口大概率补不回来：公开逐日历史端点不稳定，Tushare 补洞需要自备 token 且积分门槛较高，当日快照端点只给当日值。

审计与回填子命令的 `--anchors` **必填**——本工具不预置默认板块，锚点要按自己实际跟踪的板块传。

## 可选问财

策略选股和部分 ETF 查询需要用户自行安装 `hithink-market-query`，然后在配置中加入其 `scripts/cli.py` 绝对路径：

```json
{
  "wencai_cli": "/absolute/path/to/hithink-market-query/scripts/cli.py"
}
```

如该工具需要凭据，只在本机环境配置 `IWENCAI_API_KEY`，不得写进 JSON 或仓库。

## 可选付费与本地证据

- `hithink-finance`：用户自行安装和认证；不可用时降级。
- `ifind_evidence_helper`：只接受配置中的 canonical helper 路径；数据截止日以 helper 每次输出为准。
- `news-search` / `report-search` / `hithink-industry-query`：许可证尚未确认，不进入发行包；自行安装后分别用 `ASM_NEWS_SEARCH_CLI`、`ASM_REPORT_SEARCH_CLI`、`ASM_INDUSTRY_QUERY_CLI` 指向入口。

任何可选组件不可用时都必须在输出中明示，不得回退到作者目录。
