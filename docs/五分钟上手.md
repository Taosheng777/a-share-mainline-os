# 五分钟上手

## 1. Clone

```bash
git clone https://github.com/Taosheng777/a-share-mainline-os.git
cd a-share-mainline-os
```

## 2. 安装三套 Skill

Codex：

```bash
bash adapters/codex/install.sh
```

Claude Code：

```bash
bash adapters/claude/install.sh
```

安装器默认拒绝覆盖已有同名 Skill；确需升级时先确认备份，再设置 `ASM_FORCE_INSTALL=1`。

也可从 marketplace 安装（推荐）：

- Claude Code：`/plugin marketplace add Taosheng777/a-share-mainline-os`，然后 `/plugin install a-share-mainline-os@a-share-mainline-os`。
- Codex：`codex plugin marketplace add Taosheng777/a-share-mainline-os`，然后 `codex plugin add a-share-mainline-os@a-share-mainline-os`。

## 3. 建空 vault 与配置

```bash
cp -R vault-template "$HOME/a-share-mainline-vault"
mkdir -p "$HOME/.config/a-share-mainline"
python3 -c 'import json,pathlib; p=pathlib.Path.home(); d={"vault_root":str(p/"a-share-mainline-vault"),"git_identity":{"default":"[ai]","claude":"[ai:claude]","codex":"[ai:codex]"}}; f=p/".config/a-share-mainline/config.json"; f.write_text(json.dumps(d,ensure_ascii=False,indent=2)+"\n")'
```

打开 `01-纪律卡.md`，自行填写三条线。空阈值不会被 AI 猜补。

## 4. 安装免费数据 Skill

```bash
python3 adapters/shared/install_a_stock_data.py \
  --target "$HOME/.codex/skills/a-stock-data"
```

Claude 用户替换目标目录。第三方依赖和可选问财见 [配置与可选数据源](配置与可选数据源.md)。

## 5. 运行

在新任务中说：

- `执行最新交易日复盘`
- `为我已立项的主线筛选 ETF 和龙头股`
- `用 stock-buddy 体检这条主线`

仓库自检：

```bash
python3 scripts/cold_start.py
```

该命令在临时 HOME 中安装、配置并运行离线复盘前置与载体筛选，不读取现有用户目录。
