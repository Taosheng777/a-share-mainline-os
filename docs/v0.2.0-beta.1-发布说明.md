# v0.2.0-beta.1 发布说明

这一版不增加新的交易判断逻辑，重点把首个 beta 从“可以安装”推进到“可以安全升级、公开复现和外部贡献”。

## 主要变化

- 统一使用 `VERSION` 作为 `0.2.0-beta.1` 机器事实源，插件、marketplace、冷启动、归档和测试不再各自写死版本。
- 建立公开 canonical source `src/skills/`；任何公开 clone 都能确定性重建 Claude/Codex 分发树，不依赖作者私人目录。
- 新增安全安装器：显式 upgrade、dry-run、同批次备份、失败恢复和最近版本回滚；不读取或修改用户 config 与 vault。
- 新增只读 `doctor`，检查产品 Skill、配置、vault 合同和免费数据 Skill，并区分可选数据源。
- 增加升级/回滚文档、安装反馈与功能建议 Issue 表单、macOS 安装与回滚 smoke。

## 兼容性

- 旧 `ASM_FORCE_INSTALL=1` 仍兼容，推荐改用 `--upgrade`。
- 用户现有 config 与 vault 无需迁移；模板新增 metadata 只用于新建 vault，不自动写入旧 vault。
- `v0.1-beta` 历史 tag 与附件保持不变。

## 验证

- 离线门共 335 项测试：产品合同 20、vault 合同 5、双平台 Skill 310。
- Python 3.11/3.12 Ubuntu 离线发布门。
- macOS 14 首次安装、升级、回滚与冷启动 smoke。
- 公开 source 双平台逐字节再生。
- 临时 HOME 中验证 config/vault 在升级与回滚前后指纹不变。
- 私人路径、疑似凭据、账户附件与插件许可证审计。
