# 连续研究与影子对照

该层默认关闭，不需要它也能继续复盘、分析和筛选。它把「上次为什么这样判断、今天依据什么改判」记录下来，并提供同一载体的研究路径比较；它不接券商、不管理真实账户、不证明收益优势。

## 在自己的 vault 启用

须先完成 [五分钟上手](五分钟上手.md)。以下是一次由使用者明确选择的配置操作，安装器和日更都不会自动执行。

1. 将 `config/研究运行配置.example.json` 复制为 vault 的 `00-系统/投资运行配置.json`。如果该文件已存在，逐项合并并保留原件，不覆盖现有配置。
2. 将 `config/研究运行合同.example.md` 复制为配置所指的 `00-系统/研究运行合同.md`，并将 `config/研究验证状态.example.json` 复制为 `00-系统/研究验证状态.json`。它的 method_version 须与配置一致。保持 `profitability: not_established`；工程检查通过不能自行晋级。
3. 在自己授权的 vault 内创建配置指定的四个空 JSONL 文件。空账本表示尚无记录，不能导入作者历史或伪造以前的前瞻判断。若已存在则保留。系统只支持该研究合同列出的模型标识；实际执行模型不符时明确报告，不能修改 model 字段冒充。
4. 在安装后的 stock-daily 目录运行 `python3 scripts/system_check.py --vault <你的vault绝对路径>`。支持 macOS/Linux、Python 3.11+；记录锁使用 POSIX flock，尚不支持 Windows 原生 Python。路径必须在 vault 内。

## 每轮合同

先按 [运行流程](../src/skills/stock-daily/references/astra-workflow.md) 读最新记录，再形成判断，写入前执行账本校验。主题研究、可交易载体和当前行动分开；改变建议须说明触发的旧条件或新证据。模型字段填写实际执行模型，合同不会替宿主切换模型。纪律和预注册失效条件继续从原文件读取，不另存第二套阈值。

前三类行情通道保留调用顺序及权威性规则。数据缺失时报告缺口，不能让账本字段制造「关键数据已齐全」的假象。跨日补录只能用 historical_audit；前瞻记录按系统真实录入时刻判定证据可得性。

主影子链及 hold/trend 基线使用不同文件、固定方法版本、同一载体和同一个初始研究时点。hold 维持原单位持有，trend 使用预先锁定的 MA20 退出对照；退出后同一研究事件不重新进场。三链纪律输入相同，不能故意让基线违规。MA20 只是研究对照，不写入真实纪律。没有可核验资产、研究进场或完整 MA20 时，说明不可评估，不造样本。

## 独立试用记录工具

不启用完整运行层，也可以在自己指定的研究目录使用以下标准库工具：

```bash
python3 scripts/decision_journal.py status --journal <连续决策.jsonl>
python3 scripts/decision_journal.py append --journal <连续决策.jsonl> --record <本次决策.json>
python3 scripts/decision_journal.py validate --journal <连续决策.jsonl>
python3 scripts/shadow_compare.py --input <锁定研究输入.json> --output <结果.json>
```

记录示例、字段和校验边界见 [连续决策合同](../src/skills/stock-daily/references/decision-journal.md)，行情、可执行性、成本与前瞻收据要求见 [影子对照合同](../src/skills/stock-daily/references/shadow-comparison.md)。不能仅凭一份结果 JSON 声称策略有效；历史诊断、合成测试、前瞻模拟必须分别标记。哈希链不提供跨设备分布式锁，也不能防止有权限者重写整条链。

`decision_ops` 是使用者另行提供的项目适配器，本仓库不附带候选回填脚本、真实日历、行动台账或作者项目数据。接入边界见 [项目运行层](../src/skills/stock-daily/references/project-runtime.md)。

公开分享的输出保留研究工具声明、实际数据来源和数据日。本人本地使用 screen.py/danger_scan.py 可显式设 `ASM_OUTPUT_AUDIENCE=personal`；此选项只控制声明文案，不授权发送、发布或交易。
