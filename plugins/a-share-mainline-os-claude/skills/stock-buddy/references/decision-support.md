# AI 决策支持层（金融专家模式）

本页定义金融专家模式在五维研究与纪律核对之后，如何给出**明确但可审计的投资建议**。它不是纪律卡，也不是交易执行器。

## 三层合同

1. **纪律层**：只读 `01-纪律卡.md` 当前三条线。纪律触发可直接否决建议，但建议不得反过来改写、豁免或新增纪律。
2. **AI 建议层**：给出行动倾向、置信度、证据权重、估值或情景目标区间、风险预算仓位区间，以及判断最可能错在哪里。
3. **用户执行层**：用户确认并自行交易。AI 不下单、不碰委托、不动资金，不把建议伪装成已执行事实。

输出不能以“决定由你”代替分析。先给 AI 的明确建议，执行边界只在末尾说明一次。

## 行动倾向

固定使用：`退出 / 减仓 / 持有 / 观望 / 试仓 / 加仓`。同时给：

- 置信度：低 / 中 / 高；
- 证据权重：支持几项、反对几项，分别是什么；
- 最容易忽略的一条事实；
- 本判断最可能错在哪里，以及什么新证据会改变建议。

纪律与风险标签对行动倾向的映射是硬门，不存在“建议层豁免纪律”的后门：

- 纪律①触发：该主线全部机动仓只能给 `退出`，建议目标总仓位为 `0%`；
- 纪律②触发：该标的只能给 `退出`，建议目标总仓位为 `0%`；
- 纪律③触发：不得给 `试仓 / 加仓`；已有持仓只能在 `退出 / 减仓 / 持有 / 观望` 中按证据裁决，未持仓保持 `观望`；
- 风险标签“否决”：已有持仓给 `退出` 并减至 `0%`，未持仓给 `观望` 且目标总仓位为 `0%`。

行动与仓位必须做一致性校验：`退出` 对应目标总仓位 `0%`；`减仓` 的目标总仓位低于当前实际仓位；`加仓` 高于当前实际仓位；数据不足时不得用 `持有` 掩盖无法判断。

## 目标区间：三类不得混写

### 1. 外部机构目标区间

只汇总可验证的券商或机构观点，逐条标机构、发布日期、目标价、估值口径与原始来源。过期资料仍可展示，但必须显著标注发布日期，不得冒充当前共识，**不得进入当前目标区间摘要或消息评分**；发生拆分、分红等公司行动时，只有写明调整方法后才能与当前价比较。

### 2. AI 估值 / 情景区间

- 用悲观 / 基准 / 乐观三档，不给伪精确的单点目标。
- 写清方法、关键假设、预测期、对应催化剂与证伪条件；个股可用 PE、PEG、DCF、分部估值等可解释方法，ETF 或缺乏可审计盈利锚点的标的改用底层指数 / 成分情景，不硬套公司估值。ETF 缺跟踪指数、成分暴露或相应估值锚时，不得硬给目标区间。
- AI 估值所用财务、行业与当前价必须标同一 `as-of` 数据日。拿机构历史目标与当前价比较时，必须同时写“研报发布日期 + 当前价数据日”；可计算情景上涨或下跌空间，但不写“保证收益”“必到价”。
- 数据不足以支持估值时，写 `无法形成可审计的目标区间（缺口：…）`。不得拿技术阻力位、券商目标价或记忆值冒充 AI 估值。

### 3. 技术参考位

进场、失效、减仓与复评位只描述价格行为和技术锚点。技术位不是估值目标，必须另表展示。

## 仓位建议：风险预算法

仓位是**本次、带数据日的 AI 建议**，不是纪律、不是当前持仓账本，也不写回 `01-纪律卡.md`。本页的“单笔风险预算%”统一指**该笔触及失效位时，计划最多损失占账户总资产的比例**；“仓位%”统一指该标的市值占账户总资产的比例。最终建议一律表示**建议目标总仓位**，不是“本次再买多少”；已有持仓时必须并列当前实际仓位与数据日，并给出 `建议变动 = 目标总仓位 − 当前实际仓位`。

基础计算：

`止损距离 = |参考入场价 − 失效位| ÷ 参考入场价`

`理论仓位% = 单笔风险预算% ÷ 止损距离`

参考入场价与失效位必须使用同一数据日、同一复权 / 拆分口径；A 股多头场景中失效位应低于参考入场价。基础公式假设能在失效位成交，因此还必须给**跳空 / 跌停 / 滑点压力情景**：能以历史波动估算就展示压力止损距离与压力损失，估不出就标“尾部成交风险未量化”并下调仓位上限。

AI 技术失效位可以用于敏感性试算，但它不是纪律②的真实止损位。未经用户明确确认，不得把 AI 技术失效位登记到持仓卡或主线页「我的操作」区，也不得声称纪律②已经生效；模板必须同时标“失效位性质”和“用户确认状态”。

首席必须明确展示参考入场价、失效位、止损距离、建议的单笔风险预算区间和计算结果，再依次取以下上限中的最小值：

1. 裁决与置信度上限；
2. 风险标签上限（风险否决 = 0%）；
3. 主线阶段与死亡条件余量；
4. 当前同因子暴露后的剩余额度；
5. 可用资金、非杠杆 100% 上限、流动性与一手可执行性。

单笔风险预算区间是本轮 AI 假设，必须解释其与波动、置信度和账户承受度的关系，并至少展示上下沿敏感性；**不得直接复用任何已废除的 v2 固定风险比例**。止损距离必须大于 0，参考入场价与失效位方向不合理、结果非有限数或缺任一输入时，停止仓位计算并列缺口。

每个上限都要写明数值与理由，不能用隐藏系数。最终输出**仓位区间 + 中心值 + 失效位账户风险区间 + 压力情景账户风险区间**，不把一个精确百分比写成强制命令。

个性化仓位采取 fail-closed：缺当前账户快照、快照不是同一交易日且用户未确认之后无交易，或缺同因子暴露时，只能展示风险预算公式与情景敏感性，**不得形成个性化仓位区间、中心值或建议变动**。若连参考入场价或失效位都没有，则只列补数清单。不得编造账户总资产、现有仓位或可用资金。实际金额与股数只有在总资产、可用资金和一手规则均可验证时才换算。

## 有效期与写回

建议在以下任一项变化时失效并需重算：价格数据日、参考入场价、失效位、主线阶段、风险标签、账户快照或同因子暴露。

专家模式从载体名单接力时，写回主线页：

- `AI 决策建议`：行动倾向、置信度、证据权重、主要反方与失效条件；
- `估值与情景区间`：三类价格信息分开；
- `AI 仓位建议`：风险预算、公式、区间、中心值、上限与有效期。

每次建议以带数据日的折叠快照追加；可以更新本区顶部的“当前摘要”，但不得覆盖或删除旧版建议、旧目标和旧仓位区间，确保建议变化可追溯。

真实持仓事实仍只由券商截图或用户报告更新；建议仓位不得冒充当前仓位。
