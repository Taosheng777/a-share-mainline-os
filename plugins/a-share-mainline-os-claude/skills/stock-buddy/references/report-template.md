# 载体研判报告模板（专家模式产出 → 写回主线页）

v3 的专家模式产出**不是独立决策页**（`07-交易决策/` 已归档），而是写进所属主线页的「载体清单」「参考条件位」「AI 决策建议」「估值与情景区间」「AI 仓位建议」五区。本模板给对话内呈现的结构；写盘时按主线页的既有表格格式落位，不要把整篇模板原样贴进主线页。

## AI 仓位建议（personal-aware）

| 项 | 内容 |
|---|---|
| 当前实际仓位 | _%（券商截图 / 用户报告数据日 _；是否确认之后无交易：是 / 否） |
| 参考入场价 / AI 技术失效位 | |
| 失效位性质 / 确认状态 | 技术试算位；是否已由用户确认成纪律②真实止损：是 / 否 |
| 止损距离 | `|入场价−失效位|÷入场价 = _%` |
| 价格口径 | 同一数据日、同一复权 / 拆分口径 |
| 单笔风险预算 | _%–_%（AI 假设、依据与上下沿敏感性；不得复用废除的 v2 硬线） |
| 理论仓位 | `风险预算÷止损距离 = _%–_%` |
| 压力情景 | 跳空 / 跌停 / 滑点假设；压力止损距离与账户风险，无法量化则标缺口并降上限 |
| 显式上限 | 置信度 / 风险 / 主线阶段 / 同因子暴露 / 可用资金 / 非杠杆 100% / 流动性：逐项列数值与理由 |
| 建议目标总仓位 | 区间 _%–_% · 中心值 _%（占账户总资产，不是本次增量） |
| 建议变动 | 目标总仓位 − 当前实际仓位 = _ 个百分点；方向：退出 / 减仓 / 不变 / 加仓 |
| 风险结果 | 失效位账户风险 _%–_% · 压力情景账户风险 _%–_% |
| 有效期 | 数据日 _；价格、失效位、主线、风险或账户快照变化即重算 |

> 这是本次 AI 建议，不是纪律，也不是当前持仓。账户快照非同交易日且未确认之后无交易、缺账户快照或缺同因子暴露时，只展示公式与情景敏感性，不形成个性化仓位区间、中心值或建议变动；缺入场价或失效位时也不计算。

> 每次写回用带数据日的折叠快照追加；顶部当前摘要可更新，旧建议不得覆盖或删除。未经用户确认的 AI 技术失效位不得写成纪律②真实止损。

## 落盘前自检（写主线页之前逐条过，任一条不过就别写）

这三条是强制检查。漏了不是风格问题，**是把本来可核验的结论写成了不可核验的**。

| # | 检查项 | 判定标准 | 漏了会怎样（实测） |
|---|---|---|---|
| 1 | **每个价位都有技术锚点** | 「参考条件位」表必须保留**依据**列，每个数字写清出处：均线（写明 MA 几 + 数值）／当日开·收·高·低／近 N 日平台高低点／跳空缺口／用户设定止损位。锚不到就**明写「无技术锚点」**——不许留空、不许整列省略 | 页面从可核验退回「AI 说的」；任何无法回溯到技术锚点的数字都视为失败 |
| 2 | **资金维度展示当日 / 5 日 / 10 日三行** | 有评分就必须有三周期**展示**，不是只写结论。ETF 无个股主力资金流 → 用所跟踪行业的板块资金流，并**写明是代理口径**；**基金份额申赎 ≠ 主力资金流**，两者不可互相顶替；某周期取不到写「未取得（原因）」，**不许拿别的周期的数字填** | 只看单周期可能把短期脉冲误读为持续趋势 |
| 3 | **纪律阈值只引用不抄写** | 页面写指针（`[[01-纪律卡]]` + 「现读不固化」）。确需给出数字时，必须同句写明「截至 YYYY-MM-DD 该值为 X，纪律卡改基准即失效，以卡为准」 | 纪律卡一改基准，主线页那个数不会跟着变，两处从此打架且没人知道哪个对 |

自检未通过又必须落盘时：把不通过项作为**已知缺口**显式写进页面（像「ETF 成分未逐一核验」那样），不要静默略过。
