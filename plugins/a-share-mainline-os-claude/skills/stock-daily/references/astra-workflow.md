# Astra 完整复盘运行层

仅当运行时 vault 的 `00-系统/投资运行配置.json` 中 `workflow` 为 `astra_full_v1` 才启用；未配置继续原协议，不影响其他用户。

读取该配置指向的合同（相对路径必须位于 vault 内）、验证状态、journal与shadow_journal，并执行合同规定的完整Astra流程。执行模型为配置 `allowed_models` 之一（在项目合同中选择），记录的 model 必须是当轮实际模型，不能靠写字段冒充；不改全局模型，不增加API调用。

该模式覆盖本skill下方的Codex前段/Claude后段角色分配。当轮执行模型（GPT-6 Astra 或 Claude）同一轮完成机械池、原后段全量催化核查、正式提名、反方复核。先锁数据与池，再写结论；同模型顺序自检不能标成跨模型独立验证；接手另一模型上一轮的结论只是接续，也不算独立验证。用户明确只要机械前段时，仍交“③ 候选池（机械扫描，未取舍）”并标未提名。

## 日常必须接入的两个工具

1. 决策前：`python3 <skill>/scripts/decision_journal.py status --journal <vault>/<journal>`，按稳定theme_id读取上一建议。不存在旧记录时从首次记录起，不事后伪造早期判断。
2. 写回前：按 [decision-journal.md](decision-journal.md) 生成本轮record，再 `append --journal ... --record ...`；然后 `validate --journal ...`。只有成功才称连续决策记录完成。详细record放本轮workspace的work内，JSONL追加到配置路径。

正式提名、明确拒绝/撤回、活跃主线、当前主题持仓方向都要记录；同一主题当天合并一条最终建议，别把多个重叠BK算多个机会。仅有市场榜单且未形成具体判断时不编造主题记录。真实确认单独引用用户原话/截图来源；AI建议的动作从不代表用户执行。

## 判断规则

主题类型与研究逻辑、载体可参与性、当前行动分开。继承原硬纪律、原死亡判定版本与既有规则冻结。新shadow字段不得升级为任意通用否决门槛；触发频率不得叫误报率。未通过原立项门槛仍不建页，但说明究竟是主题反证、数据缺失还是规则适用性未验证。

跨日只在先前条件触发、新事件或用户新指示下改判；维持也需本日证据。改变失效条件需要明确版本与原因，不得每日加严后说原预测正确。权益类ETF等风险资产“停泊”不等于现金或空仓。

## 研究模拟，不是日常账户绩效

[shadow-comparison.md](shadow-comparison.md)说明同标的完整路径对照。输入不足时输出not_evaluable；不能用板块收盘价冒充ETF可成交价。不要为凑验证样本自动触发实际交易或每天重跑历史参数扫描。

## 写回范围

Astra模式在既有日更四类白名单基础上，仅增加配置指向的建议/影子JSONL追加。验证状态的工程/收益等级只在专门体系验收时更新，日更不自行晋级。项目合同优先，日志保持五区且正文便于扫读，机器数据不塞入阅读正文。

## 影子基线记录

当前主题具备可核验载体与进场假设时，在当天价格后续未知前分别追加：主影子链（AI方法）、配置baseline_journals.hold（同入场持续持有）、baseline_journals.trend（锁定MA20价格趋势对照）。同一theme_id、同一research_asset；每个文件的method_version独立。无明确研究进场、缺可交易载体或缺完整MA20数据时标未验证，不造目标凑样本。影子目标为标准化研究比例，不是用户仓位。

两基线初次均以AI首个研究enter为共同起点，研究比例沿用该首个目标；hold基线此后仅hold（硬纪律触发也按同边界exit），trend基线在收盘低于截至当日MA20时exit，退出后本主题事件不重新进入。该MA20只是预注册对照，未证有效，不写进真实纪律。每次复盘追加三条同日记录或明确缺口；不同链的纪律输入相同，不能让基线故意违反硬纪律制造优势。未运行三链时不能声称完成全路径对照。没有活跃研究事件时保持空账本，不伪造观察样本。

使用`python3 <skill>/scripts/system_check.py --vault <vault>`检查入口、账本及验证等级。它只检查配置一致性，不替代行为测试或模型身份核验。

## 决策优化完成条件

配置含 `decision_ops` 时先读其 contract，执行其中候选追加、行动到期检查、宽度触发器及 daily 回填；成功读取结果才算该部分完成。项目脚本统一位于 vault，勿复制出第二套业务实现。
