# 载体交接与条件位（v3）

本流程用于从 `stock-screener` 的**载体筛选**结果继续，为某条已立项主线产出可决策的载体排序与参考条件位。

v2 的「选股批次 → 唯一首选 → 交易决策页」流程已停用（`07-交易决策/` 已归档）。v3 的终点是**主线页**，不是决策页。

> **五个层级互不替代**：载体筛选排名 ≠ 专家裁决 ≠ 纪律约束 ≠ AI 决策建议 ≠ 用户实际执行。AI 必须给明确倾向，但任何一层通过都不等于系统已下单。

## 接力输入

- **所属主线页**：叙事、死亡条件、当前阶段、已有载体清单。**没有立项主线就没有载体交接**——先走 `mainline-workflow.md` 的提名答辩。
- `stock-screener` 产出的载体候选：ETF 与龙头股名单、相关度依据、流动性与弹性指标、数据日、字段缺口。
- 当前纪律卡、持仓卡（角色与止损位）。
- 用户明确限制（如不能买创业板、科创板、某类标的）。

## 完整流程

1. 从主线页读叙事与死亡条件，从 screener 结果读候选，**不重新发明第二套筛选**。
2. **账户适配**：排除已持仓标的（除非是加仓讨论）、无交易权限标的、无法按一手执行的高价股、流动性不足以按计划进出的标的。v2 的集中度/现金/持仓数量硬线已废除，**不要再套**；受约束的只有纪律卡那三条。
3. **相关度校验**：候选是否真的承载这条主线的叙事。主题 ETF 要看成分与主线的实际重叠，不能只看名字像。名不副实的直接剔除并说明。
4. **强弱排序**：给出排序与**每一位的排序理由**，理由必须可溯源到具体数据（资金承接、相对强度、成交额、弹性、跟涨跟跌比）。
5. 需要深度分档时才进专家模式（技术 / 资金 / 消息研报 / 基本面行业 / 风险五个独立 sub-agent），评分与权重规则见下。
6. **参考条件位**：为排序靠前的载体给进场参考、加减仓参考、退出参考，每个都带依据与数据日。
7. **专家模式决策支持**：按 `decision-support.md` 给行动倾向；能审计才给目标区间，personal-aware 路由给风险预算仓位区间。
8. 写回主线页。常规档只更新「载体清单」与「参考条件位」；专家模式另更新「AI 决策建议」「估值与情景区间」「AI 仓位建议」。当轮提交。

## 评分与风险（仅专家模式）

- 技术、资金、消息研报、基本面行业分别按 `-2..+2` 评分；默认权重 `25% / 30% / 20% / 25%`。当期规则另有明确权重时以当前事实源为准。
- 展示每个维度的评分、权重、加权贡献、主要依据、加权总分和完整公式。
- 风险维度用「通过 / 警示 / 否决」，不参与数值加权并独立行使否决权。
- **综合分是同批相对排名，不是买入评级**；风险否决与纪律卡优先于排名与总分。

## 写回主线页

### 载体清单区

| 排序 | 载体 | 代码 | 类型 | 排序理由 | 数据日 |

- 按日可刷新；排序变化要留痕，不要静默覆盖。
- 载体名单进入 **T+N 跟踪**，验证的是「AI 载体排序准不准」，不是「这只票涨没涨」。

### 参考条件位区

| 类型 | 参考位 / 信号 | 依据 | 数据日 |
|---|---|---|---|
| 进场参考 | | | |
| 加减仓参考 | | | |
| 退出参考 | | | |

**必须带的话**：技术条件触发不等于系统执行；AI 给出建议，用户确认并自行交易。

### 专家模式 · AI 决策支持区

按 `decision-support.md` 写行动倾向、证据权重、三类价格信息和风险预算仓位。建议仓位与当前仓位必须分栏，且标数据日与失效条件。每次用带数据日的折叠快照追加，旧建议不覆盖；AI 技术失效位未经用户确认，不得登记成纪律②真实止损。

### 不写的东西

- 不建 `07-交易决策/`、`08-下个交易日/`、`06-交易记录/`（均已归档）。
- 不维护当前持仓数量、成本、市值、盈亏与仓位账本——绩效和账户事实交给同花顺 / 券商截图。
- 不把技术阻力位冒充估值目标，不给无方法、无假设、无数据日的单点目标价。
- 不把 AI 建议仓位冒充当前持仓，也不把建议写进纪律卡。

## 最新持仓截图对账后

1. 更新 `03-持仓跟踪/持仓.md` 的当前四字段：标的、角色、所属主线、止损位；**止损位只登记用户明确确认的真实纪律止损**，AI 技术失效位未确认时留空。
2. 主线页「我的操作」区只记差异：对账日 / 新增、清仓、数量变化或角色变化 / 标的 / 当前状态；不记录逐笔成交价、成交数量、时间与理由。
3. 两次截图之间的操作视为既成事实，不追溯、不反推、不做账户算术核对。截图内数量与成本只用于识别差异和当轮风险结构，不滚动维护成账本。
4. 当轮提交。AI 不下单、不碰委托、不动资金。

## 载体失效或主线退潮

- 载体因相关度下降或流动性恶化被移出清单时，在主线页留痕说明原因，不静默删除。
- 主线退潮 → 走 `mainline-workflow.md` 的退潮复核，联动纪律①。
- 主线页与载体证据**永久保留**；归档时整页移入 `05-主线追踪/归档/`。
