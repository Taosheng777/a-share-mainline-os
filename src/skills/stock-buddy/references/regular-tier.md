# 常规档工作流（单 agent · personal-aware · 明确建议、不代执行）

## 流程
1. `source ~/.zshrc`。读 discipline.md（若涉持仓）。
2. 取数：按 parsing.md 模板跑行情→技术→资金→（个股加）基本面。持仓标的额外算"相对成本盈亏"。
3. 按"状态层 + 信号判定 + AI 建议 + 危险信号"组织输出。

## 状态层（不预测）
每个标的/板块输出三件事：
1. 趋势状态：上升/下降/震荡（均线排列 + 价格相对 MA5/10/20/60 的位置）。
2. 企稳信号清单：逐条列"成立/未成立"——缩量止跌？站上 MA5/10？站上 MA20？站上 MA60？MACD 翻红/零轴上方？主力净流入？板块共振？次日确认（留待）？**不给"已企稳"的拍脑袋结论。**
3. 位置提示：现价在近期区间（持仓另含成本）中的位置 + 有无主力承接。

## 信号判定（带纪律护栏）
- 进场信号：成立 / 不成立 / 观察 + 置信度（低/中/高）。
- 触发价：站上什么价位逻辑才成立。
- 失效位=止损：跌破什么价位逻辑作废。
- 纪律对照：以 `discipline.md` 指向的 `01-纪律卡.md` 三条线为准，**阈值运行时读、不固化**。v2 曾固化的个股、主题 ETF、同主题、现金和单笔风险等具体硬线**已全部废除，不得再套或从旧记录恢复**。
- 机动仓必须带：所属主线当前阶段 + 距止损位百分比；底仓不套纪律①②，只做月度体检。
- **AI 建议**：固定给 `退出 / 减仓 / 持有 / 观望` 之一，附置信度、证据权重、主要反方与改判条件；常规档不做估值目标或风险预算仓位，用户要求这两项时走专家模式门控。
- 执行边界：不下单、不生成委托；不能用“由你决定”代替建议。

## 危险信号
按 discipline.md 的清单，触及即先红字提示，再谈其余。

**个股情报三层扫描（持仓体检默认跑；单票速查按需）**：

```bash
python3 "<stock-buddy skill目录>/scripts/danger_scan.py" <code...> [--date YYYY-MM-DD] [--json out.json] [--deep-news]
```

`--date` 仅定义风险扫描基准日/回溯与前瞻窗口锚点，不代表所有子结果共享同一数据日；各自日期和窗口以输出 `data_caliber` 与正文为准。

- **第一层 · 硬风险**：解禁（未来90天）/ 巨潮公告风险词（60天）/ 融资余额5日急变（±8% 红字）/ 互动易回复率。脚本自带红字判定，输出时红字先行（与纪律触线合并排序）。
- **第二层 · 免费快讯**：腾讯取公司名，财联社取最新50条全市场电报并按公司名/代码过滤（当前接口 `rn` 上限为50，传100会成功但返回空数组）。`命中=[]` 只表示该覆盖范围内零命中，**不等于无新闻**；来源失败写「来源不可用、未形成媒体新闻结论」。
- **第三层 · 公司新闻深搜**：仅当用户当轮明确要求深搜该标的时显式加 `--deep-news`；用公司名调用问财 `news-search`，会消耗共享问财额度。发现重点风险但用户未授权时只提示可深搜，默认绝不自动调用；结果由上游 CLI 直接输出，不在扫描器内二次重组。
- ETF 自动跳过（三层情报不适用于 ETF）。东财个股新闻已退出默认主源，不再输出固定的「东财间歇风控未跑」。
- 结果为 T3 爬取源：引用须标来源+日期；**数字不入台账**，与 hithink（T1/T2）冲突以后者为准。

## 输出
对话内 Markdown 表格/清单，默认不存。结尾固定使用主 `SKILL.md` 的完整运行时声明，必须同时覆盖研究与决策支持、非持牌证券投资咨询、不构成投资建议、不代下单、风险自担，以及本次实际数据来源和数据日。

## T+N 跟踪（特例：要回写）

v3 的 T+N 验证对象是**主线载体名单**——验的是「AI 载体排序准不准」，不是「这只票涨没涨」。

- **主线载体 T+N**（v3 主用）：取载体最新收盘，按状态层点评，回写所属主线页的「载体清单」区（排序是否需要调整 + 理由），阶段有变化时同步「证据流」。
- 总览不保存逐只明细，不另建第二份事实源。
