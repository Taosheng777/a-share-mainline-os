# 主线追踪

主线是一等对象，生命周期为：提名 → 启动 → 发酵 → 分歧 → 退潮 → 归档。

## 建页规则

- AI 提名必须给证据、反方和可判定的死亡条件雏形。
- 用户说“跟”才建页；不拍板不建页。
- 必须先写死亡条件，没有死亡条件的主线不建页。
- 触发不等于执行；系统只提示，不下单。

## 证据流

证据流每行必须带数据日与来源。阶段变化时保留旧证据，不静默覆盖。

## 生命周期

| 阶段 | 含义 |
|---|---|
| 提名 | 待用户拍板 |
| 启动 / 发酵 / 分歧 | 按当日证据更新 |
| 退潮 | 预注册死亡条件成立，联动纪律提示 |
| 归档 | 退潮后封存完整证据链 |
