# 连续研究运行合同（示例）

仅在使用者选择启用后生效。按已安装 stock-daily 的 references/astra-workflow.md、decision-journal.md 与 shadow-comparison.md 执行；配置须与本合同一起审阅。

模型须与 allowed_models 及宿主实际身份相符。同轮完成机械候选、催化核查、正式取舍和反方复核，用户另有明确范围时从其范围。只运行一种模型不能称作跨模型独立验证。

决策前读连续账本，按同主题同模式续接；改判引用旧条件、新事件或用户真实指示。纪律不另设阈值，AI建议不是用户执行。新增写入只限配置中且已获授权的账本，保留前后快照与同轮提交。

三条影子链使用同载体、同初始研究事件和各自锁定的方法版本；hold 持续持有、trend 使用预注册 MA20 退出，三者共用相同纪律输入。输入缺失即不可评估，不补造样本。

本合同未建立盈利资格。工程检查、历史诊断与前瞻研究分别记录，不以其中之一替代其他证据。不得代下单、生成委托、自动交易或创建定时任务。
