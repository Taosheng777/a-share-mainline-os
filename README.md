# A 股主线研究与决策支持系统

`a-share-mainline-os` 是面向 A 股主线生命周期的研究与决策支持 Skill 套件。当前仓库处于 `v0.1-beta` 本地构建阶段；本提交先固定许可证、第三方依赖和投资工具边界，安装与冷启动结构将在下一阶段加入。
